# Changelog

All notable changes to this project will be documented in this file.

## 0.2.0 — 2026-09-17

### 🎉 Features

- Add resolveOutputStyle and detectOutputStyle to toolbelt.terminal (#340)

  - Adds `resolveOutputStyle` to the `/candidate` subpath of `@williamthorsen/toolbelt.terminal`, which chooses `rich` or `plain` output by reading a CLI flag first, then an environment variable, then detection, with `auto` from either source deferring to detection.
  - Adds `detectOutputStyle`, which returns `rich` only when `CI` is unset, empty, or `'false'`, the stream is a terminal, and `TERM` is not `linux`, and `plain` otherwise.
  - Adds `describeInvalidOutputStyle`, which composes the usage message naming the accepted settings, since `resolveOutputStyle` returns a value that names no style in an `invalid` field rather than throwing.

- Add a glyph set with rich and plain variants to toolbelt.terminal (#341)

  - Adds `defineGlyphSet` to `@williamthorsen/toolbelt.terminal/candidate`, which pairs a rich and a plain rendering under each name and derives every glyph's terminal width from the rules that it enforces: a rich glyph is one `Emoji_Presentation` code point outside the regional indicators and two cells wide, and a plain glyph is printable ASCII and as wide as its length.
  - Adds `measureGlyphColumn`, which reports the widest glyph of one style in a set, so a caller pads a column to a derived width instead of a hardcoded gutter that a longer word silently invalidates.
  - Adds `STATUS_GLYPHS`, a set giving each of `blocked`, `failed`, `info`, `passed`, `skipped`, and `warning` a rich glyph and a plain uppercase word, with `passed`, `failed`, and `skipped` told apart by shape rather than by hue alone.

- Add width measurement, wrapping, and truncation to toolbelt.terminal (#342)

  - Adds `measureWidth`, `wrapToWidth`, and `truncateToWidth` to the `/candidate` subpath of `@williamthorsen/toolbelt.terminal`, each measuring text in terminal columns rather than UTF-16 length, so `wrapToWidth` and `truncateToWidth` keep a wide character or emoji whole, close every ANSI style that they open, and exceed the requested width only for a word wider than it or an indent that reserves every column of it.
  - Declares the package's first third-party runtime dependencies: `cli-truncate`, `slice-ansi`, `string-width`, and `wrap-ansi`, which install nine packages in all for every consumer of `@williamthorsen/toolbelt.terminal`, including one importing only `resolveOutputStyle`.
