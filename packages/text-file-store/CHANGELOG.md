# Changelog

All notable changes to this project will be documented in this file.

## 0.2.0 — 2026-11-22

### 🎉 Features

- Adds the `FileStore` interface, whose `read`, `write`, and `remove` resolve to a result naming why an operation failed (a missing file, a name already held, a refused write, or a store out of reach) rather than throwing. (#780)
- Adds `createWebStorageFileStore`, which keeps each file under a key prefix in a Web Storage area such as `localStorage` and reports a write past the area's quota as refused. (#780)
- Adds `createHttpFileStore`, a `FileStore` client for a server that implements the HTTP protocol documented in the package README. (#780)
- Adds `createMemoryFileStore`, an in-memory `FileStore` with a clock independent of the system's and an `isUnreachable` flag that makes every method report the store as out of reach, for testing a caller's failure handling. (#780)

### 🏗️ Internal features

- Adds the empty `@williamthorsen/toolbelt.text-file-store` package, scaffolded from `packages/_template`, and registers it in the records that `__tests__/package-registration.app.unit.test.ts` checks and in the `pnpm-lock.yaml` importers. (#778)
